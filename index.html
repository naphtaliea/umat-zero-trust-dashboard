About This Dashboard

This dashboard is a practical implementation of the NIST Special Publication 800-207 Zero Trust Architecture framework, designed specifically for the University of Mines and Technology (UMaT) with its dual-campus structure across Tarkwa and Takoradi.

Why Zero Trust for UMaT?

Traditional perimeter-based security assumes that users inside the campus network can be trusted. Zero Trust rejects this assumption. With UMaT operating across two campuses approximately 90 km apart, connected by fiber, cross-campus access creates unique trust evaluation challenges that this system addresses.

How Trust Scoring Works

Every access request is evaluated by a Policy Decision Point (PDP) that computes a contextual trust score (0–100) based on six weighted factors: device compliance, network location, user identity verification, MFA status, resource sensitivity tier, and a novel cross-campus context signal. Scores ≥ 70 are allowed, 45–69 trigger step-up MFA, and scores < 45 are denied.

Architecture Reference

The Subject → PEP → PDP (PE + PA) → Resource pipeline follows the logical architecture defined in NIST SP 800-207, Section 3 (Logical Components). The cross-campus context signal is an extension that models the geographic and administrative separation between the Tarkwa and Takoradi campuses as a first-class trust dimension.
